# THE PIECE 주보

포도나무교회 청년교구 주보를 만드는 도구입니다.
배경 이미지를 올리고 광고 문서를 붙여넣으면 **페이지가 알아서 나뉘고**, 바로 이미지로 받아
밴드에 올릴 수 있습니다. 매주 미리캔버스에서 손으로 하던 작업을 대체합니다.

## 무엇이 달라지나

| 지금까지 | 이 도구 |
|---|---|
| 미리캔버스에서 광고를 하나씩 옮겨 배치 | 구글 문서 내용을 **통째로 붙여넣으면 자동 분할** |
| 각 페이지 상단 날짜를 일일이 수정 | 날짜 **한 번만** 입력 → 전 페이지 자동 반영 |
| 표지 더피스 로고가 유료(건당 약 1,100원) | 로고 **기본 포함**, 결제 불필요 |
| 분량에 맞춰 사람이 페이지를 나눔 | 실제 높이를 재서 **자동으로 나눔** (제목·본문은 항상 붙어 있음) |
| 매주 처음부터 다시 | 지난 주보 **복사해서 시작** |

## 시작하기

```bash
npm install
npm run dev
```

http://localhost:3000 에서 열립니다.
같은 와이파이의 폰이나 태블릿에서도 터미널에 표시되는 Network 주소로 접속할 수 있습니다.

## 화면 구성

```
[ 주보 만들기 ]  [ 보관함 ]                       2026.08.02.주일  [저장]
  전체 공통 | 고정 페이지 | 본문 작성 | 전체 보기
```

| 탭 | 적용 범위 | 하는 일 |
|---|---|---|
| **전체 공통** | 모든 페이지 | 날짜 · 배경 이미지 · 교회 정보(하단 푸터) |
| **고정 페이지** | 앞 2장 | ① 표지(글자·퍼즐 로고) ② 청년부 일정(예배 안내·월별 생일) |
| **본문 작성** | 3장부터 | 광고 붙여넣기 · 블록 편집 · 주요일정 · 본문 말씀 |
| **전체 보기** | 완성본 | 전체 페이지 확인 + **이미지 내보내기** |
| **보관함** | — | 저장한 주보 열기·복사·삭제, 만들었던 이미지 다시 받기 |

## 매주 하는 일

1. **전체 공통** — 날짜를 이번 주일로, 배경 이미지 교체 (밴드에 올라온 날짜 없는 버전)
2. **본문 작성** — 목사님이 올린 광고 문서를 복사해서 `붙여넣기` 버튼에 그대로 붙여넣기
3. **전체 보기** — 확인하고 `전체 N장 이미지 내보내기`
4. `저장` 후 **전체 보기 > 교회 QR > 이 주보를 QR에 올리기** — 입구에 붙인 QR이 이번 주 주보를 보여줍니다.
   이미지는 밴드에 올립니다

지난주 것을 그대로 쓰려면 **보관함 → 복사해서 새로**를 누르면 날짜가 다음 주일로 바뀐 사본이 생깁니다.

## 주요 기능

### 광고 붙여넣기 파서

구글 문서 광고 전문을 붙여넣으면 블록으로 나눕니다. 우선순위는 다음과 같습니다.

1. `<...>` `[...]` `【...】` 로 감싼 줄 → 블록 제목 (노란 형광펜 자동 적용)
2. 빈 줄 → 블록 구분
3. `1.` `-` `▶` 같은 글머리 기호로 시작하는 줄 → 제목 후보
4. 어느 것도 안 맞으면 첫 줄을 제목으로 가정하고 **확인 필요** 표시

변환 결과를 미리 보여주므로 확정 전에 확인할 수 있습니다.

### 교회 QR

QR은 한 장만 뽑아 입구에 붙여두면 됩니다. 주소가 `/now` 하나로 고정이고, 매주 **올리기**만
누르면 같은 코드가 이번 주 주보를 보여줍니다.

```
저장  →  아직 아무에게도 안 보임
올리기 →  페이지 이미지를 만들어 함께 올리고, /now 가 이 주보를 보여줌
내리기 →  /now 가 다시 닫힘 (주보와 QR 주소는 그대로)
```

- **저장과 공개를 갈라 둡니다.** 작성 중인 주보가 새어 나가지 않습니다
- 잠금은 화면이 아니라 **DB 함수**(`get_current_bulletin`)에 있습니다. 올리지 않은 주보는
  주소를 알아도 열리지 않습니다
- 교인 폰에서는 **올릴 때 만든 페이지 이미지**를 보여줍니다. 인쇄물과 한 픽셀도 다르지 않고,
  폰이 폰트를 내려받아 조판을 다시 계산하지 않아 바로 뜹니다
- 지금 무엇이 올라가 있는지는 **전체 보기 → 교회 QR** 과 보관함의 `QR에 올라감` 배지로 봅니다
- **로그인 없이 누구나 열립니다.** 교인이 폰으로 찍어 들어오는 자리라 계정이 필요 없습니다
- 열려 있는 주소는 `/now` 하나뿐입니다. 주보마다 따로 있던 링크는 없앴습니다 —
  쓰이지도 않는데 두면 열리는 문만 하나 더 늘어납니다
- QR 이미지는 256 · 512 · 1024 · 2048 · **2480(A4 300dpi)** px 중에 골라 PNG로 받습니다.
  고른 크기로 다시 그리므로 키워도 흐려지지 않습니다 (인쇄물은 1024px 이상 권장)
- 주보는 Supabase에 저장되므로 **교회 밖 어디서나** 열립니다 (같은 와이파이가 아니어도 됩니다)

> QR은 서버 모드에서만 씁니다. 로컬 모드(환경변수 없음)에서는 주보가 이 브라우저에만 있어
> 다른 기기가 가져갈 곳이 없습니다 — [SETUP.md](./SETUP.md)를 보고 Supabase를 연결하세요.

> 주소를 아는 사람은 누구나 볼 수 있습니다. 생일 명단이 들어가므로 QR을 공개된 곳에 붙일 때는
> 그 점을 감안해주세요.

### 생일 명단 붙여넣기 파서

**고정 페이지 → 생일 명단**에서 받은 명단을 그대로 붙여넣으면 정리해 넣습니다.
해마다, 적는 사람마다 모양이 달라도 이름과 날짜만 찾아냅니다.

```
홍길동   3월 17일      홍길동, 3-17       - 홍길동 (3월 17일)
홍길동	3/17          홍길동 1988.3.17   3월 17일 홍길동
```

- **한 줄에 세 명씩**, 날짜순으로 세웁니다 — `홍길동 3월 7일 | 김철수 3월 12일 | 이영희 3월 15일`
- **태어난 해는 읽는 즉시 버립니다.** 주보에 쓰이지 않고 나이를 특정할 수 있는 값이라
  어디에도 저장하지 않습니다
- 몇 달치가 한꺼번에 와도 달별로 갈라 각 달 칸에 넣습니다
- 날짜를 못 찾은 줄(`2월 30일` 같은 없는 날짜 포함)은 버리지 않고 그대로 보여줍니다
- 넣은 뒤에도 명단 칸에서 손으로 고칠 수 있습니다. 주보에는 적은 그대로 나갑니다

> 주보에 담기는 것은 **그 주보 달의 명단 하나뿐**입니다. QR로 들어온 사람이 다른 달 명단까지
> 들여다볼 수 없도록 저장할 때 잘라냅니다(`src/lib/backend/map.ts`).

#### AI 자동 구분 (선택)

`GEMINI_API_KEY`를 넣어두면, 붙여넣은 뒤 잠깐 기다리는 사이에 Google AI Studio(Gemini)가
제목과 내용을 갈라 원문 순서 그대로 채워 넣습니다. 위 규칙에 맞지 않게 적힌 광고도 나뉩니다.

**원문은 한 글자도 바뀌지 않습니다.** AI가 돌려준 글자를 그대로 쓰지 않고, 공백을 뺀 원문에서
같은 자리를 찾아 *원문 조각*을 잘라 씁니다(`src/lib/ai/anchor.ts`). 자리를 못 찾거나 원문 일부를
빠뜨렸으면 AI 결과를 버리고 규칙 방식 결과를 대신 보여줍니다.

키를 넣는 곳은 프로젝트 최상위의 `.env.local` 입니다.

```bash
# .env.local  (git에 올라가지 않습니다)
GEMINI_API_KEY=여기에_발급받은_키
```

키는 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 발급합니다.
`NEXT_PUBLIC_`을 붙이면 브라우저에 노출되니 붙이지 마세요. 키가 없으면 규칙 방식으로만 동작합니다.

쓰는 모델은 `gemini-3.6-flash` 이며 `src/lib/ai/gemini.ts`의 `MODEL` 한 줄로 바꿉니다.
(`gemini-2.5-flash`는 신규 사용자에게 닫혔습니다. 쓸 수 있는 모델은
`curl "https://generativelanguage.googleapis.com/v1beta/models" -H "x-goog-api-key: 키"` 로 확인합니다.)

### 자동 페이지 분할

화면 밖에서 블록을 실제 스타일 그대로 그려 높이를 재고, 카드 안쪽 높이에 맞춰 채웁니다.
**제목과 본문은 한 덩어리**라 페이지 경계에서 절대 잘리지 않습니다.
블록 하나가 한 페이지보다 크면 넘침 경고가 뜹니다 — 폰트 크기를 줄이거나 블록을 나누면 됩니다.

특정 블록 앞에서 강제로 페이지를 나눌 수도 있습니다.

### 표지 서식

표지 글자는 이미지가 아니라 **편집 가능한 서식**입니다. 문구만 고쳐 쓰면 되고 줄 추가·삭제도 됩니다.

- 곡선 글자(SVG `textPath`) — 휘어짐이 **양수면 ∩(위로), 음수면 ∪(아래로)**
- 글자별로 글꼴 · 크기 · 세로 위치 · 자간 · 휘어짐 · 색 조절
- 퍼즐 로고는 직접 그린 SVG가 기본 포함 (`public/logo/the-piece.svg`).
  네 조각이 실제로 맞물리는 구조이며, 교회 로고가 따로 있으면 업로드해 교체합니다

### 스타일 조절

아무것도 건드리지 않아도 완성본이 나오고, 필요할 때만 손대면 됩니다.

```
테마 전역  →  페이지 타입 기본값  →  요소별 수정
```

수정한 항목만 저장되므로 **↺ 기본값으로** 버튼으로 언제든 되돌릴 수 있고,
수정된 항목에는 파란 점이 표시됩니다.

### 내보내기

| 항목 | 값 |
|---|---|
| 캔버스 | 891 × 1260 (A4 세로 비율) |
| 배율 | 2배 1782×2520 / **3배 2673×3780** / 4배 3564×5040 |
| 형식 | **JPG**(용량 작아 공유에 유리) / PNG(무손실) |
| 파일명 | `2026-08-02_1.jpg` … 순번 |

만든 이미지는 보관함에 함께 저장되어 나중에 그대로 다시 받을 수 있습니다.

> 사진 배경을 쓰면 PNG는 장당 10MB를 넘길 수 있습니다. 밴드·카톡 공유에는 JPG를 권합니다.

## 데이터가 저장되는 곳

환경변수 유무에 따라 두 가지로 동작합니다. 화면은 똑같습니다.

| | 로컬 모드 (기본) | 서버 모드 |
|---|---|---|
| 조건 | Supabase 환경변수 없음 | 환경변수 있음 |
| 로그인 | 없음 | 이메일 + 비밀번호, **메일 인증 + 관리자 승인 필요** |
| 주보·설정 | `localStorage` | Supabase Postgres |
| 이미지 | `IndexedDB` | Supabase Storage |
| 기기 간 공유 | ❌ 브라우저를 바꾸면 사라짐 | ✅ 어느 기기에서나 동일 |

작성 중인 주보는 두 모드 모두 브라우저에 임시 보관되어, 저장을 누르지 않고 새로고침해도 남습니다.

## 서버 연결하기 (로그인·승인 켜기)

**➡️ [SETUP.md](./SETUP.md) 에 클릭 순서까지 적어두었습니다.** 약 15분 걸립니다.

요약하면 이렇습니다.

1. Supabase 프로젝트 생성 (무료 플랜)
2. `SQL Editor`에서 `supabase/migrations/` 안의 `001`부터 `006`까지 번호 순서대로 실행
3. `Authentication`에서 **Confirm email** 켜기 + `Confirm signup` 메일 서식에 **`{{ .Token }}`**(6자리 인증번호) 넣기 + **SMTP 연결**
4. `Project Settings > API`에서 **Project URL**과 **anon public** 키 복사
5. Vercel 환경변수에 등록하고 **재배포** (저장만으로는 반영되지 않습니다)
6. 본인이 **가장 먼저 가입** — 첫 가입자가 최고 관리자가 됩니다

> ⚠ `service_role` 키는 어디에도 넣지 마세요. 모든 권한을 우회하는 키이며,
> `NEXT_PUBLIC_`으로 시작하는 값은 브라우저에 그대로 노출됩니다.

### 가입 구조

세 가지가 **모두** 있어야 계정이 만들어집니다.

```
초대코드 + 이름·비밀번호  →  메일로 온 6자리 인증번호  →  바로 이용
 (24시간, 최대 10명)                                     (코드가 만료됐으면 승인 대기)
```

- **초대코드가 없으면 계정 자체가 만들어지지 않습니다.** 화면이 아니라 계정을 만드는
  DB 트리거에서 막으므로, 가입 요청을 직접 보내도 통과하지 못합니다
  (아무도 없는 새 DB의 첫 사람만 예외입니다 — 코드를 줄 관리자가 아직 없기 때문입니다)
- **메일 인증은 링크가 아니라 6자리 인증번호**입니다. 가입 화면에서 그대로 넣으면 끝납니다
- 코드는 계정을 만들기 전에 **확인만** 하고, 실제 사용 횟수는 **인증을 마친 뒤에** 올라갑니다 —
  인증하지 않은 사람이 남의 몫을 축내지 않게 하기 위해서입니다
- 접근 통제는 화면이 아니라 **DB의 RLS 정책**으로 막습니다. 주소를 직접 쳐도 승인 전에는 아무것도 보이지 않습니다
- 비밀번호는 **오른쪽 위 자기 이름 → 비밀번호 바꾸기**에서 스스로 바꿉니다. 지금 비밀번호를 한 번 더
  물어봅니다 — 사무실 컴퓨터 하나를 여럿이 쓰다 로그아웃을 잊었을 때 계정을 통째로 빼앗기지 않게 하려는 것입니다.
  잊어서 못 들어오는 경우는 로그인 화면의 **비밀번호를 잊으셨나요?**(메일 링크)를 씁니다

### 관리자가 하는 일

| | 최고 관리자 | 관리자 | 편집자 |
|---|---|---|---|
| 주보 작성·수정 | ✅ | ✅ | ✅ |
| 승인 · 거절 · 로그인 차단 | ✅ | ✅ | ❌ |
| 초대코드 발급 · 폐기 | ✅ | ✅ | ❌ |
| **관리자 임명 · 회수** | ✅ | ❌ | ❌ |

- **최고 관리자**는 가장 먼저 가입한 한 사람입니다. 관리자를 세우고 내리는 권한은 이 계정만 갖습니다.
  다른 관리자는 최고 관리자 계정을 고치거나 차단할 수 없습니다
- **메일 인증 여부**는 이름 옆 배지로 보입니다. 인증 전인 사람은 승인 버튼이 잠깁니다
- **로그인 차단**은 쓰던 사람을 즉시 막습니다. 계정과 주보는 남고, 차단을 풀면 그대로 이어 씁니다

> **누구도 자기 자신을 차단하거나 자기 역할을 바꿀 수 없습니다.** 화면에서 버튼을 감출 뿐 아니라
> DB 정책과 트리거로도 막아두었습니다 — 스스로를 잠그면 되살릴 사람이 없기 때문입니다.
